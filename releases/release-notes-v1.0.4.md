# PPHLX Compiler v1.0.4 — Local Dev Server & UX Updates

We are pleased to announce the release of **PPHLX v1.0.4**. This version introduces a fully integrated, zero-config local PHP development server directly into the CLI, alongside refined console log formatting and critical WebAssembly execution compatibility updates for Windows systems.

## What's New in v1.0.4

### 🚀 Integrated Local PHP Development Server
Starting with v1.0.4, running `npx pphlx dev` (or `pphlx watch`) automatically spins up a local PHP development server in the background targeting your project's configured output directory (`outDir`). You no longer need to manually manage separate PHP server processes to preview your compiled component layouts.

### ⚡ Refined CLI Developer Experience
We have rewritten the command line output logs to deliver a clean, professional developer experience matching modern industry standards (inspired by Astro CLI):
* Standardized startup headers displaying ready time, local URL, and network exposure flags.
* Removed noisy console emojis and paths from the watch environment.
* Quieter, responsive file system watcher status reporting.

### 🧩 Core WebAssembly Performance & Stability
* **Go WASM Execution Engine**: Switched the Node.js CLI runtime environment from Node's experimental `WASI` module to Go's native WebAssembly runner shim (`wasm_exec.js`). This resolves persistent Windows filesystem directory-reading (`readdirent: not implemented`) bugs under Node.js, and removes the `ExperimentalWarning` startup message entirely.
* **Robust Error Recovery**: Fixed a nil-pointer dereference crash in the underlying Go compiler when formatting JSX/JS component compilation errors generated by the esbuild builder.

### 📱 Responsive Layout Enhancements
* Updated spacing rules and collapsed accumulative padding thresholds on narrow mobile screens (under `768px`) for multiframe dashboards, maximizing card layout width and eliminating content overlaps.

## Supported Architectures (Included Assets)
This release includes precompiled native binaries and archives for the following architectures:
* `pphlx-darwin-amd64.tar.gz` (macOS Intel)
* `pphlx-darwin-arm64.tar.gz` (macOS Apple Silicon M1/M2/M3/M4/M5+)
* `pphlx-linux-amd64.tar.gz` (Linux Intel)
* `pphlx-linux-arm64.tar.gz` (Linux ARM)

## Quick Start

### Installation (macOS & Linux via Homebrew)
```bash
brew tap pphlx/tap
brew install pphlx
```

### Installation (Node.js / NPM)
```bash
npm install pphlx
```

### Start Development Server
```bash
npx pphlx dev
```
