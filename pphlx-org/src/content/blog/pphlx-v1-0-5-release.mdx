We are introducing **PPHLX v1.0.5**, focusing on developer onboarding speed, automated script setups, and local preview environments.

## What's New in v1.0.5

### 🚀 Zero-Config Post-Install Scripts
NPM installations now automatically register standard scripts (`dev`, `start`, `watch`, `build`, `preview`, `check`) inside your project's `package.json` so you can start writing code immediately.

### 🐘 Native Live Preview Mode (`preview`)
Preview compiled production builds locally with a built-in lightweight PHP routing wrapper:
```bash
pphlx preview
```

### 🔍 Diagnostic Check Core (`check`)
Validate component declarations and logic tag syntaxes directly in the compiler terminal.
