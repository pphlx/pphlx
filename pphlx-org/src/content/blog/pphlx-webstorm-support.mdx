The PPHLX ecosystem continues to grow!

[WebStorm](https://www.jetbrains.com/webstorm/) -- the popular integrated development environment (IDE) for JavaScript and web development by [JetBrains](https://twitter.com/JetBrains) -- has just announced initial support for PPHLX templates and `.pphx` files.

With today's update, WebStorm users get an improved development experience for PPHLX projects. New features include:

-   **Syntax Highlighting**: Easily read mixed HTML, inline PHP tags, and framework imports.
-   **Code Completion**: Get intelligent recommendations for components and native PHP functions.
-   **Formatting**: Keep your `.pphx` layouts cleanly formatted with built-in code formatting rules.

To get started, you can download the official PPHLX plugin from the JetBrains Marketplace, or search for "PPHLX" in your WebStorm plugins panel. We're excited to see JetBrains support the PHP-monolith developer ecosystem!
