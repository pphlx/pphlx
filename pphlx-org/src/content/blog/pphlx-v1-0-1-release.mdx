We are introducing **PPHLX v1.0.1**, adding interactive development workflows and automation commands.

## What's New in v1.0.1

### 🚀 Hot Reloading Watcher (`dev`)
Run local watch servers compiling templates dynamically in the background on every file change:
```bash
pphlx dev
```

### 📦 Boostrapping Commands (`init`)
Easily scaffold new PPHLX workspaces:
```bash
pphlx init
```

### 🧩 Automatic Island Extraction
Automatically detect React/Vue/Svelte components inside layouts and bundle them dynamically using Vite.
