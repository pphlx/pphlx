We are excited to share **PPHLX v1.0.4**, offering fully-automated background web servers, standardized WASI environments, and beautiful dev server CLI formats.

## What's New in v1.0.4

### 🏎️ Embedded Dev Server Routines
Starting with v1.0.4, running `pphlx dev` automatically spawns a local PHP router session in the background.

### 🧩 Standard WASM Execution Layer
Refactored the compiler execution layer to use the standard `wasm_exec.js` runner, eliminating experimental node warnings and Windows directory-reading compatibility bugs.

### 📝 Astro-Style CLI Logging
Enjoy clean, standardized terminal startup logs with gray headers and green state boxes.
