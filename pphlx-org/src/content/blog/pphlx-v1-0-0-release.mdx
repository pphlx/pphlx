We are thrilled to launch **PPHLX v1.0.0**, the initial public release of our high-performance component compiler.

## What is PPHLX?

PPHLX is a fast, zero-dependency layout compiler written in Go that compiles component-based PHP templates (`.pphx`) into standard, standalone, production-ready `.php` files. It bridges modern client-side workflows (React, Vue, Svelte) with backend PHP engines, resolving includes and islands server-side with zero production runtime dependencies.

## Key Core Features

*   **Islands Hydration**: Run React, Vue, SolidJS, and Svelte interactive components side-by-side on the same PHP page.
*   **Asset Extraction**: Automatically bundle CSS and JavaScript blocks into unified stylesheets and scripts.
*   **Zero Production Runtime**: Outputs standard, clean, database-ready PHP assets.
