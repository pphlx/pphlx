We are excited to share **PPHLX v1.0.2**, optimizing local template watchers, resolving compilation locks, and refining AST parsers.

## What's New in v1.0.2

### 🏎️ AST Parsing Optimizations
*   **Reduced Compiler Latency**: Optimized Go compiler routines to parse nested components faster, reducing AST generation overhead.
*   **Throttled Rebuilds**: The dev server watch engine now buffers rapid successive updates to prevent file-locking conflicts.

### 🐛 Bug Fixes
*   **Framework Bundling**: Fixed Svelte, SolidJS, and TresJS components compiling under isolated Windows path scopes.
*   **Asset Mapping**: Resolved production packaging bugs where some asset mappings were missing from the production directory.
