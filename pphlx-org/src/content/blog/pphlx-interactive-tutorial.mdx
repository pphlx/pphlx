Reading documentation is helpful, but sometimes you just need to get hands-on and build!

We are excited to share our first official project-based guide: **The PPHLX Tutorial**.

## Learn by Coding

In this tutorial, you will build a PPHLX website from scratch. You will:

1.  **Install the Compiler**: Download and configure the Go-compiled `PPHLX` binary.
2.  **Author `.pphx` Layouts**: Write your first templates mixing HTML and native server-side PHP tags.
3.  **Mount Framework Islands**: Add interactive Svelte and React elements side-by-side on the page.
4.  **Deploy the Site**: Compile files and drop them onto a shared server or theme directory.

The tutorial is designed to be accessible to everyone—whether you are an experienced PHP developer new to modern frontend frameworks, or a frontend engineer looking to target traditional monolithic backends without running Node.js.
