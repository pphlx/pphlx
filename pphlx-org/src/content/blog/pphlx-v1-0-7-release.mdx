We are proud to release **PPHLX v1.0.7**, adding native cross-platform targets to compile your layout and business logic directly into desktop binaries and mobile project workspaces.

## What's New in v1.0.7

### 💻 GPU-Accelerated WebView Native Windows (`desktop`)
Build lightweight desktop applications utilizing Edge WebView2 on Windows (CGO-free, producing compact ~9.4MB binaries) and Safari/GTK WebKit on macOS/Linux.

### 🔌 Standard Desktop Drivers & Extensions
Interoperate with the host OS natively in JavaScript via the `pphlx.desktop` API. Automatically compile custom Go extensions located in `src/desktop/` and bind them to client-side scripts.

### 📱 Android & iOS Scaffolding
Scaffold full, ready-to-run Android Studio projects (`--target android`) and Swift Xcode workspaces (`--target ios`) preloaded with your compiled layout assets.
