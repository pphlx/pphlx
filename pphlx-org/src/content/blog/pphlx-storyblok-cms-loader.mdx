Storyblok is a popular headless CMS that provides a visual editor for content managers. 

With the **Storyblok Loader**, you can sync your space's stories directly into PPHLX Content Collections during the build phase:

```ts
import { defineCollection } from "PPHLX:content";
import { storyblokLoader } from "PPHLX-storyblok-loader";

const landingPages = defineCollection({
  loader: storyblokLoader({
    token: process.env.STORYBLOK_API_TOKEN,
    spaceId: process.env.STORYBLOK_SPACE_ID,
    version: "published",
  }),
});

export const collections = { landingPages };
```

This compiles your Storyblok schema fields locally, allowing you to access them inside Svelte/React component islands or PHP templates natively.
