Because PPHLX compiles your `.pphx` templates into standard multi-page PHP files (which serve layouts via standard server request cycles), every link click traditionally triggers a browser page refresh.

But thanks to the new web platform **View Transitions API**, you can now get fluid, app-like transitions between page loads natively in the browser—with **zero client-side JavaScript required**.

## Leveraging Native View Transitions

The View Transitions API is supported natively in modern browsers. When you click a link, the browser handles the animation transition automatically as part of the navigation flow.

Instead of writing complex router code, you can enable these transition effects across your pages using just three lines of vanilla CSS inside your global layout template:

```css
@view-transition {
  navigation: auto; /* enabled! */
}
```

## Why this matters for PHP Monoliths

For years, if you wanted smooth page animations in platforms like WordPress or custom PHP setups, you had to install heavy SPA routers (like Turbo/Pjax), which often broke third-party scripts and introduced memory leaks.

With native View Transitions, the browser handles everything:
*   **No router overhead**: Pages behave like standard, secure PHP navigation cycles.
*   **Instant transitions**: Transitions feel fluid and responsive, even when loading fresh dynamic contents from your PHP database.
*   **Zero JS**: No extra library weight is shipped to the client.
