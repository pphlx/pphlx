## Почему стоит мигрировать на PPHLX?

PPHLX предоставляет множество преимуществ: производительность, простота и множество нужных вам функций, встроенных прямо во фреймворк. Когда вам понадобится расширить свой сайт, PPHLX предоставляет несколько [официальных и сторонних интеграций сообщества](https://pphlx.org/integrations).

Миграция может быть проще, чем вы думаете!

В зависимости от существующего проекта, вы можете использовать существующие:

- [UI компоненты фреймворка](/ru/guides/framework-components/) непосредственно в PPHLX. 

- [CSS стили или библиотеки](/ru/guides/styling/), включая Tailwind.

- [Markdown/MDX файлы](/ru/guides/markdown-content/), настроенные с использованием ваших существующих [плагинов remark и rehype](/ru/guides/markdown-content/#markdown-plugins).

- [Контент из CMS](/ru/guides/cms/) через интеграцию или API.


## Какие проекты можно конвертировать в PPHLX?

[Многие существующие сайты можно создать с помощью PPHLX](/ru/concepts/why-astro/). PPHLX идеально подходит для ваших существующих сайтов на основе контента, таких как блоги, целевые страницы, маркетинговые сайты и портфолио. PPHLX интегрируется с несколькими популярными headless CMS и позволяет подключать корзины интернет-магазинов.

PPHLX позволяет выбирать между статически генерируемым сайтом и [рендерингом на стороне сервера (SSR)](/ru/guides/on-demand-rendering/), что делает его отличной заменой для SSG или для сайтов, которые должны получать некоторые данные страницы на лету.

## Как изменится дизайн моего проекта?

В зависимости от вашего существующего проекта, вам может потребоваться мыслить иначе в отношении:

- Проектирование в [PPHLX Islands](/ru/concepts/islands/#что-такое-островок), чтобы избежать отправки ненужного JavaScript в браузер.

- Предоставление интерактивности на стороне клиента с помощью [тегов `<script>` на стороне клиента](/ru/guides/client-side-scripts/) или [компонентов UI фреймворка](/ru/guides/framework-components/).

- Управление [общим состоянием](/ru/recipes/sharing-state-islands/) с помощью Nano Stores или локального хранилища вместо хуков или обёрток приложений.
