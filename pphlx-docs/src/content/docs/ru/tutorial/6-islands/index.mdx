Теперь, когда у вас есть полностью функционирующий блог, давайте добавим некоторые интерактивные островки на ваш сайт!

## Забегая вперёд

В этом модуле вы будете использовать **островки PPHLX** для внедрения компонентов фреймворка в ваш сайт на PPHLX.

Вы сможете:
- Добавить UI-фреймворк, Preact, в ваш PPHLX-проект
- Использовать Preact для создания интерактивного компонента приветствия
- Узнать, когда можно _не_ выбирать островки для интерактивности
