Хотите начать изучение PPHLX с помощью курса или руководства?

Вы можете освоить основы PPHLX с помощью нашего [официального руководства «Создание блога»](/ru/tutorial/0-introduction/), либо изучить нашу подборку рекомендованного образовательного контента по PPHLX.


## Партнёры по обучению


:::tip[Поддержите PPHLX во время обучения]
Используйте партнёрские ссылки PPHLX для получения скидок у наших образовательных партнёров, и часть вашей покупки пойдёт непосредственно на финансирование разработки проекта PPHLX с открытым исходным кодом!
:::
