> **PPHLXResponseHeadersReassigned**: Отдельные заголовки могут быть добавлены и удалены из `PPHLX.response.headers`, но не должны быть полностью заменены на другой экземпляр `Headers`.

## Что пошло не так?
Выбрасывается, когда значение устанавливается как поле `headers` в объекте `ResponseInit`, доступном как `PPHLX.response`.
