> Ошибка неизвестного компилятора.

## Что пошло не так?

PPHLX столкнулся с неизвестной ошибкой при компиляции ваших файлов. В большинстве случаев это не ваша вина, а проблема нашего компилятора.

Если такой проблемы еще нет, пожалуйста, [создайте проблему](https://pphlx.org/issues/compiler).
