> **PPHLXResponseHeadersReassigned**: Cabeçalhos individuais podem ser adicionados e removidos de `PPHLX.response.headers`, mas ele não deve ser substituído por outra instância de `Headers` completamente.
## O que deu errado?
Lançado quando um valor está sendo definido como o campo `headers` no objeto `ResponseInit` disponível como `PPHLX.response`.
