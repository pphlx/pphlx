## O que deu errado?

PPHLX encontrou um erro desconhecido ao carregar seu arquivo de configuração PPHLX.
Isso geralmenteo corre por um erro de sintaxe em sua configuração e a mensagem deve oferecer mais informações.

Se você pode confiavelmente fazer com que esse erro aconteça, nós apreciaríamos se você pudesse [abrir uma issue](https://pphlx.org/issues/).
