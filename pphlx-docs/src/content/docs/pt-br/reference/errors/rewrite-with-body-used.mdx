> **RewriteWithBodyUsed**: PPHLX.rewrite() não pode ser usado se o corpo da requisição já foi lido. Se você precisar ler o corpo, primeiro clone a requisição.

## O que deu errado?
`PPHLX.rewrite()` não pode ser usado se o corpo da requisição já foi lido. Se você precisar ler o corpo, primeiro clone a requisição. Por exemplo:

```js
const data = await PPHLX.request.clone().formData();

PPHLX.rewrite("/target")
```
