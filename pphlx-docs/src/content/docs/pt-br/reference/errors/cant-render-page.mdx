> **CantRenderPage**: PPHLX não conseguiu encontrar um conteúdo para renderizar nesta rota. Não há arquivo ou redirecionamento associado a esta rota.
## O que deu errado?
PPHLX não conseguiu encontrar um arquivo associado com conteúdo ao tentar renderizar a rota. Este é um erro do PPHLX e não um erro do usuário. Se ao reiniciar o servidor de desenvolvimento não resolver o problema, por favor, abra uma issue.
