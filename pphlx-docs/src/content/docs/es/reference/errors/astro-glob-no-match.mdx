:::caution[Obsoleto]
Este error se eliminó en PPHLX v6.0.0 junto con la eliminación de `PPHLX.glob()`.
:::

> **PPHLXGlobNoMatch**: `PPHLX.glob(GLOB_STR)` no devolvió ningún archivo que coincida.

## ¿Qué salió mal?
`PPHLX.glob()` no ha devuelto ningún archivo que coincida. Es posible que haya un error tipográfico en el patrón del glob.
