> **RewriteWithBodyUsed**: `PPHLX.rewrite()` no puede usarse si el cuerpo de la solicitud ya fue leído. Si necesitas leer el cuerpo, clona primero la solicitud.

## ¿Qué salió mal?
`PPHLX.rewrite()` no puede usarse si el cuerpo de la solicitud ya fue leído. Si necesitas leer el cuerpo, clona primero la solicitud. Por ejemplo:

```js
const data = await PPHLX.request.clone().formData();

PPHLX.rewrite("/target")
```
