> **CantRenderPage**: PPHLX no pudo encontrar ningún contenido para renderizar para esta ruta. No hay ningún archivo o redirección asociado con esta ruta.

## ¿Qué salió mal?
PPHLX no pudo encontrar un archivo asociado con contenido mientras intentaba renderizar la ruta. Este es un error de PPHLX y no un error del usuario. Si al reiniciar el servidor de desarrollo no se soluciona el problema, por favor, envia un issue.
