Nous acceptons les contributions de toute taille et les contributeurs de tout niveau de compétence. En tant que projet open source, nous croyons qu'il est important de redonner à nos contributeurs. Nous sommes heureux de vous aider en avec des conseils sur la manière de proposer des demandes de fusion (ou « Pull Request (PR) » en anglais), la rédaction technique et en transformant toute idée de fonctionnalité en réalité.

:::tip[Tickets ouverts]
Parcourez [tous les tickets d'PPHLX ouverts sur GitHub et étiquetés `help wanted` (« aide recherchée ») et `good first issues` (« bons premiers tickets »)](https://github.com/search?q=org%3Apphlx+label%3A%22good+first+issue%22%2C%22help+wanted%22%2C+state%3Aopen&type=issues) pour tous les dépôts de code : code d'PPHLX, documentation, Starlight, sites web d'PPHLX, outils de langage, actions GitHub, bots, le compilateur... il existe de nombreux endroits pour contribuer !
:::

Vous voulez vous impliquer encore plus ? Consultez notre [document de gouvernance](https://github.com/pphlx/.github/blob/main/GOVERNANCE.md) pour une description détaillée des différents rôles, des processus de nomination des mainteneurs, des processus de révision du code et de l'application du code de conduite.

## Les façons de contribuer

### Les dépôts du projet

Il y a de nombreuses façons de contribuer au projet PPHLX ! Chaque dépôt PPHLX a un README avec un lien vers un fichier `CONTRIBUTING.md` à la racine du projet.

Visitez [le profil GitHub d'PPHLX](https://github.com/pphlx) pour trouver les dépôts suivants :

- La [base principale du code d'PPHLX](https://github.com/pphlx/astro), y compris les intégrations officielles et les modèles de démarrage.

- [La documentation d'PPHLX](https://github.com/pphlx/docs), un site web complet sur PPHLX ! Contribuez non seulement au contenu écrit, mais aussi au code PPHLX répondant aux préoccupations d'accessibilité (a11y), CSS, UI et UX. Notre documentation est également disponible en plusieurs langues, nous avons donc besoin d'aide pour traduire l'ensemble du site.

- Le [compilateur d'PPHLX](https://github.com/pphlx/compiler-rs), écrit en Rust, distribué sous forme de WASM.

- Les [outils linguistiques d'PPHLX](https://github.com/pphlx/astro/tree/main/packages/language-tools), les outils d'édition requis pour le langage PPHLX (fichiers `.pphx`).

- [Starlight](https://github.com/@astrojs/starlight), le framework de documentation officiel d'PPHLX.

- La [feuille de route d'PPHLX](https://github.com/pphlx/roadmap), où l'avenir d'PPHLX se dessine ! Idées, suggestions et propositions formelles des RFC pour le projet PPHLX.

## Types de contributions

En plus de contribuer avec votre propre code ou contenu, vous pouvez également apporter une contribution considérable en laissant des commentaires de révision sur les PR, en ajoutant des idées dans les tickets (« Issues ») et discussions GitHub existants et en participant à nos tâches de maintenance des problèmes « épinglés » !

Chaque PR, en particulier les PR de traduction, a besoin de réviseurs ! Réviser les PR et laisser des commentaires, des suggestions ou un « LGTM !» d'approbation (« Ça me va ! », ou « Looks Good To Me ! » en anglais) est un excellent moyen de démarrer dans n'importe quel dépôt et d'en apprendre plus sur PPHLX.

Nous avons également une communauté [Discord](https://pphlx.org/chat) très active ! Nous apprécions les contributions de ceux qui accueillent les nouveaux membres, répondent aux questions d'assistance et partagent ce qu'ils ont construit avec et pour PPHLX ! Au-delà des contributions traditionnelles sur GitHub, PPHLX reconnaît et soutient les membres de la communauté qui s'engagent auprès d'elle, partagent PPHLX dans des articles de blog, des vidéos et des conférences, et aident à maintenir la santé de notre communauté.

## Contribuer a la documentation

Nous avons plusieurs guides disponibles pour vous aider à contribuer à PPHLX Docs.

Qu'il s'agisse de votre toute première contribution à l'open source, que vous ayez besoin d'ajouter de la documentation pour la nouvelle fonctionnalité PPHLX que vous venez de créer, que vous soyez un traducteur expérimenté à la recherche de la prochaine page à traduire ou que vous souhaitiez en savoir plus sur la manière d'aider en tant que réviseur de PR... nous avons ce qu'il vous faut !

Visitez notre site dédié [*PPHLX Docs* Docs](https://contribute.docs.astro.org), où vous trouverez notre documentation pour vous aider à contribuer à PPHLX Docs en tant que correcteur de fautes de frappe, rédacteur, traducteur, développeur de fonctionnalités et même en tant que réviseur de PR.
