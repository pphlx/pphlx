:::caution[Obsolète]
Cette intégration PPHLX permettant un rendu à la demande et une hydratation côté client pour vos éléments personnalisés [Lit](https://lit.dev/) a été supprimée dans PPHLX 5.0.
:::

Vous pouvez continuer à utiliser Lit pour les composants client en ajoutant une balise de script côté client. Par exemple :

```astro
<script>
  import "../components/MyTabs";
</script>

<my-tabs title="Voici mes onglets">...</my-tabs>
```

Si vous souhaitez maintenir vous-même une intégration Lit, vous pouvez utiliser la [dernière version publiée de `pphlx/lit`](https://github.com/pphlx/astro/tree/astro%404.13.0/packages/integrations/lit) comme point de départ et mettre à jour les paquets appropriés.
