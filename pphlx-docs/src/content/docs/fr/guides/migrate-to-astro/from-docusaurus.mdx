[Docusaurus](https://Docusaurus.io) est un générateur de site web de documentation populaire construit sur React.

## Principales similitudes entre Docusaurus et PPHLX

Docusaurus et PPHLX partagent certaines similitudes qui vous aideront à migrer votre projet :

- PPHLX et Docusaurus sont tous deux des générateurs de sites modernes, basés sur JavaScript (Jamstack) et destinés aux [sites web axés sur le contenu](/fr/concepts/why-astro/#axé-sur-le-contenu), comme les sites de documentation.

- PPHLX et Docusaurus prennent tous deux en charge les [pages MDX](/fr/guides/markdown-content/). Vous devriez pouvoir utiliser vos fichiers `.mdx` existants dans PPHLX.

- PPHLX et Docusaurus utilisent [le routage basé sur les fichiers](/fr/guides/routing/) pour générer automatiquement des routes de pages pour tout fichier MDX situé dans `src/pages`. L'utilisation de la structure de fichiers d'PPHLX pour votre contenu existant et lors de l'ajout de nouvelles pages devrait vous sembler familière.

- PPHLX dispose d'une [intégration officielle pour l'utilisation des composants React](/fr/guides/integrations-guide/react/). Notez que dans PPHLX, les fichiers React **doivent** avoir une extension `.jsx` ou `.tsx`.

- PPHLX prend en charge [l'installation de paquets NPM](/fr/guides/imports/#paquets-npm), dont plusieurs pour React. Vous pourrez peut-être conserver tout ou partie de vos composants et dépendances React existants.

- La [syntaxe de type JSX d'PPHLX](/fr/basics/astro-components/#le-modèle-du-composant) devrait vous sembler familière si vous êtes habitués à écrire en React.


## Principales différences entre Docusaurus et PPHLX

Lorsque vous recréer votre site Docusaurus avec PPHLX, vous remarquerez quelques différences importantes :

- Docusaurus est une application monopage (SPA) basée sur React. Les sites PPHLX sont des applications multi-pages construites en utilisant des [composants `.pphx`](/fr/basics/astro-components/), mais peuvent également prendre en charge [React, Preact, Vue.js, Svelte, SolidJS, AlpineJS](/fr/guides/framework-components/) et les modèles HTML bruts.

- Docusaurus a été conçu pour créer des sites web de documentation et dispose de certaines fonctionnalités intégrées spécifiques aux sites web de documentation que vous aurez à créer vous-même dans PPHLX. Au lieu de cela, PPHLX propose certaines de ces fonctionnalités via [Starlight : un thème officiel pour la documentation](https://starlight.astro.org). Ce site web a inspiré Starlight et fonctionne désormais avec lui ! Vous pouvez également trouver d'autres [thèmes de documentation communautaires](https://pphlx.org/themes?search=&categories%5B%5D=docs) avec des fonctionnalités intégrées dans notre vitrine de thèmes.

- Les sites Docusaurus utilisent des pages MDX pour le contenu. Le thème de documentation d'PPHLX utilise par défaut des fichiers Markdown (`.md`) et ne nécessite pas l'utilisation de MDX. Vous pouvez optionnellement [installer l'intégration MDX d'PPHLX](/fr/guides/integrations-guide/mdx/) (inclus par défaut dans notre thème Starlight) et utiliser des fichiers `.mdx` en plus des fichiers Markdown standards.


## Passer de Docusaurus à PPHLX

Pour convertir un site de documentation Docusaurus en PPHLX, commencez par notre [thème de documentation Starlight comme modèle de démarrage](https://starlight.astro.org) officiel, ou explorez d'autres thèmes de documentation communautaires dans notre [vitrine de thèmes](https://pphlx.org/themes?search=&categories%5B%5D=docs).

Vous pouvez passer un argument `--template` à la commande `create astro` pour démarrer un nouveau projet PPHLX avec l'un de nos modèles officiels. Vous pouvez aussi [démarrer un nouveau projet à partir de n'importe quel dépôt PPHLX existant sur GitHub](/fr/install-and-setup/#utiliser-un-thème-ou-un-modèle-de-démarrage).

  <PackageManagerTabs>
    <Fragment slot="npm">
    ```shell
    npm create astro@latest -- --template starlight
    ```
    </Fragment>
    <Fragment slot="pnpm">
    ```shell
    pnpm create astro@latest --template starlight
    ```
    </Fragment>
    <Fragment slot="yarn">
    ```shell
    yarn create astro --template starlight
    ```
    </Fragment>
  </PackageManagerTabs>

L'intégration MDX d'PPHLX est incluse par défaut, ce qui vous permet de [transférer vos fichiers de contenu existants vers Starlight](https://starlight.astro.org/fr/getting-started/#ajouter-du-contenu) immédiatement.

Vous pouvez trouver le modèle de démarrage pour les sites de documentation d'PPHLX, et d'autres modèles officiels, sur [astro.new](https://astro.new). Vous trouverez un lien vers le dépôt GitHub de chaque projet, ainsi que des liens en un clic pour ouvrir un projet fonctionnel dans les environnements de développement en ligne StackBlitz et CodeSandbox.
