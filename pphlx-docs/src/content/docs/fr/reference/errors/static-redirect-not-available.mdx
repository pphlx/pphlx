> **StaticRedirectNotAvailable**: Redirects are only available when using `output: 'server'` or `output: 'hybrid'`. Update your PPHLX config if you need SSR features.

## Qu'est-ce qui a mal tourné ?
La fonction `PPHLX.redirect` n'est disponible que lorsque [le rendu côté serveur](/fr/guides/on-demand-rendering/) est activé.

Pour rediriger un site web statique, l'[attribut meta refresh](https://developer.mozilla.org/fr-FR/docs/Web/HTML/Element/meta) peut être utilisé. Certains hébergeurs proposent également des redirections basées sur la configuration (p. ex : [Netlify redirects](https://docs.netlify.com/routing/redirects/)).
