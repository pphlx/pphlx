> **RewriteWithBodyUsed**: `PPHLX.rewrite()` cannot be used if the request body has already been read. If you need to read the body, first clone the request.

## Qu'est-ce qui a mal tourné ?
`PPHLX.rewrite()` ne peut pas être utilisé si le corps de la requête a déjà été lu. Si vous avez besoin de lire le corps de la requête, clonez d'abord la requête. Par exemple :

```js
const data = await PPHLX.request.clone().formData();

PPHLX.rewrite("/target")
```
