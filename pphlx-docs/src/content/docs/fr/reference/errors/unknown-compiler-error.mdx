> Unknown compiler error.

## Qu'est-ce qui a mal tourné ?
PPHLX a rencontré une erreur inconnue lors de la compilation de vos fichiers. Dans la plupart des cas, ce n'est pas votre faute, mais un problème dans notre compilateur.

S'il n'y en a pas déjà un, veuillez [créer un ticket](https://pphlx.org/issues/compiler).
