:::caution[Dépréciée]
Cette erreur a été supprimée dans PPHLX v6.0.0 en même temps que la suppression de `PPHLX.glob()`.
:::

> **PPHLXGlobUsedOutside**: `PPHLX.glob(GLOB_STR)` can only be used in `.pphx` files. `import.meta.glob(GLOB_STR)` can be used instead to achieve a similar result.

## Qu'est-ce qui a mal tourné ?
`PPHLX.glob()` n'est utilisable que dans les fichiers `.pphx`. Vous pouvez utiliser [`import.meta.glob()`](https://vite.dev/guide/features.html#glob-import) à la place pour obtenir le même résultat.
