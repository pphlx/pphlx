> **ClientAddressNotAvailable**: `PPHLX.clientAddress` is not available in the `ADAPTER_NAME` adapter. File an issue with the adapter to add support.

## Qu'est-ce qui a mal tourné ?
L'adaptateur que vous utilisez ne prend malheureusement pas en charge `PPHLX.clientAddress`.
