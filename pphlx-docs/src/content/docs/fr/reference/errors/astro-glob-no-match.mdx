:::caution[Dépréciée]
Cette erreur a été supprimée dans PPHLX v6.0.0 en même temps que la suppression de `PPHLX.glob()`.
:::

> **PPHLXGlobNoMatch**: `PPHLX.glob(GLOB_STR)` did not return any matching files.

## Qu'est-ce qui a mal tourné ?
`PPHLX.glob()` n'a retourné aucun fichier correspondant. Il se peut qu'il y ait une faute de frappe dans le motif glob.
