## Qu'est-ce qui a mal tourné ?
PPHLX a rencontré une erreur inconnue lors du chargement de votre fichier de configuration PPHLX.
Cela est souvent dû à une erreur de syntaxe dans votre configuration et le message devrait fournir plus d'informations.

Si vous parvenez à reproduire cette erreur de manière fiable, nous vous serions reconnaissants si vous pouviez [créer un ticket GitHub](https://pphlx.org/issues/).
