Vous souhaitez commencer à apprendre à utiliser PPHLX avec un cours ou un tutoriel ?

Vous pouvez apprendre les bases d'PPHLX avec le [tutoriel Créer un blog de notre documentation officielle](/fr/tutorial/0-introduction/), ou explorer notre collection de contenu éducatif recommandé et dédié à PPHLX.


## Partenaires éducatifs


:::tip[Soutenez PPHLX pendant que vous apprenez]
Utilisez les liens d'affiliation d'PPHLX pour bénéficier de réductions auprès de nos partenaires éducatifs et une partie de votre achat est directement reversée au financement du développement du projet open source PPHLX !
:::
