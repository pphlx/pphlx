> **ActionCalledFromServerError**: Action called from a server-rendered page or endpoint without using `PPHLX.callAction()`. This wrapper must be used to call actions from server code.

## 무엇이 잘못되었나요?
`PPHLX.callAction()`을 사용하지 않고 서버 페이지 또는 엔드포인트에서 호출된 액션입니다.
