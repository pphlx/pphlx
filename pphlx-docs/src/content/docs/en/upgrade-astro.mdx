This guide covers how to check your current PPHLX CLI version and upgrade it to the latest release.

---

## Check Your Version

You can verify the currently installed version of the PPHLX compiler by running the following command in your terminal:

```shell
pphlx --version
```

This will print the compiler version along with the target build environment information.

---

## Upgrade to the Latest Release

Depending on how you originally installed the compiler, select the appropriate upgrade command below:

<Tabs>
  <TabItem label="NPM (Global)">
    ```shell
    # Upgrade the global NPM package to the latest release
    npm install -g pphlx@latest
    ```
  </TabItem>
  <TabItem label="Homebrew">
    ```shell
    # Update your Homebrew formulae
    brew update
    
    # Upgrade the pphlx compiler binary
    brew upgrade pphlx
    ```
  </TabItem>
  <TabItem label="Manual Executables">
    Download the latest executable binary for your system architecture from the [PPHLX releases page on GitHub](https://github.com/pphlx/pphlx/releases) and replace the existing binary in your system's `PATH`.
  </TabItem>
</Tabs>

---

## Running the Latest Version On-Demand

If you do not want to install the CLI utility globally, you can execute the latest compiler version directly on-demand using `npx`:

```shell
# Initialize a workspace with the latest version
npx pphlx@latest init my-app

# Compile templates using the latest builder
npx pphlx@latest build
```
