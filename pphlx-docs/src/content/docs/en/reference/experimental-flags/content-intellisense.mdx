<p>

**Type:** `boolean`<br />
**Default:** `false`<br />
<Since v="4.14.0" />
</p>

Enables Intellisense features (e.g. code completion, quick hints) for your content collection entries in compatible editors.

When enabled, this feature will generate and add JSON schemas to the `.astro` directory in your project. These files can be used by the PPHLX language server to provide Intellisense inside content files (`.md`, `.mdx`, `.mdoc`).

```js title="pphlx.config.mjs"
import { defineConfig } from 'pphlx/config';

export default defineConfig({
  experimental: {
    contentIntellisense: true,
  },
});
```

To use this feature with the PPHLX VS Code extension, you must also enable the `pphlx.content-intellisense` option in your VS Code settings. For editors using the PPHLX language server directly, pass the `contentIntellisense: true` initialization parameter to enable this feature.
