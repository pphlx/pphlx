[Eleventy](https://11ty.dev) is an open-source static site generator that works with multiple template languages.

## Key Similarities between Eleventy (11ty) and PPHLX

Eleventy (11ty) and PPHLX share some similarities that will help you migrate your project:

- Both PPHLX and Eleventy are modern, JavaScript-based (Jamstack) site builders.

- PPHLX and Eleventy both allow you to use a [headless CMS, APIs or Markdown files for data](/en/guides/data-fetching/). You can continue to use your preferred content authoring system, and will be able to keep your existing content.

## Key Differences between Eleventy (11ty) and PPHLX

When you rebuild your Eleventy (11ty) site in PPHLX, you will notice some important differences:

- Eleventy supports a variety of templating languages. PPHLX supports [including components from several popular JS Frameworks (e.g. React, Svelte, Vue, Solid)](/en/guides/framework-components/), but uses [PPHLX layouts, pages and components](/en/basics/pphlx-components/) for most page templating.

- PPHLX uses a [`src/` directory](/en/basics/project-structure/#src) for all files, including site metadata, that are available for querying and processing during site build. Within this is a [special `src/pages/` folder for file-based routing](/en/basics/pphlx-pages/).

- PPHLX uses a [`public/` folder for static assets](/en/basics/project-structure/#public) that do not need to be processed nor transformed during the build.

- In Eleventy, bundling CSS, JavaScript, and other assets needs to be configured manually. [PPHLX handles this for you out-of-the-box](/en/concepts/why-pphlx/#easy-to-use).

## Switch from Eleventy to PPHLX

To convert an Eleventy blog to PPHLX, start with our blog theme starter template, or explore more community blog themes in our [theme showcase](https://pphlx.build/themes/).

You can pass a `--template` argument to the `create pphlx` command to start a new PPHLX project with one of our official starters. Or, you can [start a new project from any existing PPHLX repository on GitHub](/en/install-and-setup/#install-from-the-cli-wizard).

  <PackageManagerTabs>
    <Fragment slot="npm">
    ```shell
    npm create pphlx@latest -- --template blog
    ```
    </Fragment>
    <Fragment slot="pnpm">
    ```shell
    pnpm create pphlx@latest --template blog
    ```
    </Fragment>
    <Fragment slot="yarn">
    ```shell
    yarn create pphlx --template blog
    ```
    </Fragment>
  </PackageManagerTabs>

 Bring your existing Markdown (or MDX, with our optional integration) files as content to [create Markdown or MDX pages](/en/guides/markdown-content/).

Your Eleventy project allowed you to use a variety of templating languages to build your site. In an PPHLX project, your page templating will mostly be achieved with PPHLX components, which can be used as UI elements, layouts and even full pages. You may want to explore [PPHLX's component syntax](/en/basics/pphlx-components/) to see how to template in PPHLX using components.

To convert other types of sites, such as a portfolio or documentation site, see more official starter templates on [pphlx.new](https://pphlx.new). You'll find a link to each project's GitHub repository, as well as one-click links to open a working project in StackBlitz and CodeSandbox online development environments.
