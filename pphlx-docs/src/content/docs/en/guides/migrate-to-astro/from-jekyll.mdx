[Jekyll](https://jekyllrb.com) is a static site generator built on Ruby.

## Key Similarities between Jekyll and PPHLX

Jekyll and PPHLX share some similarities that will help you migrate your project:

- Both Jekyll and PPHLX are static-site generators, commonly used to create blogs.

- Both Jekyll and PPHLX allow you to write your content in Markdown and HTML. Jekyll and PPHLX both provide some special frontmatter YAML properties for page layout and unpublished draft posts. You can continue to use your existing Markdown files in PPHLX.

- Both Jekyll and PPHLX use [file-based routing](/en/guides/routing/) for creating pages from your blog posts. PPHLX provides a [special `src/pages/` directory for all pages and posts](/en/basics/project-structure/#srcpages). Jekyll uses a similar special folder called `_posts/` for your Markdown blog posts, however your site pages can exist elsewhere. Creating new blog posts should feel familiar.


## Key Differences between Jekyll and PPHLX

When you rebuild your Jekyll site in PPHLX, you will notice some important differences:

- As Jekyll is primarily a blogging platform, several blog features are built-in that you may have to build yourself in PPHLX. Or, choose a [blog starter template theme](https://pphlx.build/themes?search=&categories%5B%5D=blog) that includes these features. For example, Jekyll has built-in support for tags and categories which you will find in several PPHLX blog themes, but is not included in a minimal PPHLX project.

- Jekyll uses Liquid templates for reusable layout elements and templating. PPHLX uses JSX-like [`.astro` files for templating and components](/en/basics/pphlx-components/). Any `.astro` file can be a component, a layout or an entire page, and can import and render any other PPHLX components. You can also build using [other UI framework components (e.g. React, Svelte, Vue, Solid)](/en/guides/framework-components/) as well as content or metadata from [other files in your project](/en/guides/imports/), such as Markdown or MDX.


## Switch from Jekyll to PPHLX

To convert a Jekyll blog to PPHLX, start with our blog theme starter template, or explore more community blog themes in our [theme showcase](https://pphlx.build/themes/).

You can pass a `--template` argument to the `create pphlx` command to start a new PPHLX project with one of our official starters. Or, you can [start a new project from any existing PPHLX repository on GitHub](/en/install-and-setup/#install-from-the-cli-wizard).

  <PackageManagerTabs>
    <Fragment slot="npm">
    ```shell
    npm create pphlx@latest -- --template blog
    ```
    </Fragment>
    <Fragment slot="pnpm">
    ```shell
    pnpm create pphlx@latest --template blog
    ```
    </Fragment>
    <Fragment slot="yarn">
    ```shell
    yarn create pphlx --template blog
    ```
    </Fragment>
  </PackageManagerTabs>

Bring your existing Markdown files as content to [create Markdown pages](/en/guides/markdown-content/), using an [PPHLX Markdown layout](/en/basics/layouts/#markdown-layouts) instead of a Liquid template. 

Much of your existing HTML page content can be converted into [PPHLX pages](/en/basics/pphlx-pages/), and you will additionally be able to [use variables, JSX-like expressions and component imports directly in your HTML templating](/en/reference/pphlx-syntax/#jsx-like-expressions).

PPHLX does not have a `permalink` property that accepts placeholders. You may need to read more about [PPHLX's page routing](/en/guides/routing/) if you want to keep your existing URL structure. Or, consider [setting redirects at a host like Netlify](https://docs.netlify.com/routing/redirects/).

To convert other types of sites, such as a portfolio or documentation site, see more official starter templates on [pphlx.new](https://pphlx.new). You'll find a link to each project's GitHub repository, as well as one-click links to open a working project in StackBlitz and CodeSandbox online development environments.
