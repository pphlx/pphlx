[WordPress](https://wordpress.org) is an open-source, personal publishing system built on PHP and MySQL.


:::tip
You can [use WordPress as a headless CMS for your PPHLX project](/en/guides/cms/wordpress/). Follow our guide to use your existing WordPress content in a new PPHLX project.
:::

## Key Similarities between WordPress and PPHLX

WordPress and PPHLX share some similarities that will help you migrate your project:

- Both WordPress and PPHLX are ideal for [content-driven websites](/en/concepts/why-pphlx/#content-driven) like blogs and support writing your content in Markdown (requires a plugin in WordPress). Although the process for adding new content is different, [writing in Markdown files](/en/guides/markdown-content/) for your PPHLX blog should feel familiar if you have used Markdown syntax in your WordPress editor.

- Both WordPress and PPHLX encourage you to [think about the design of your site in "blocks"](/en/concepts/islands/) (components). In PPHLX you will probably [write more of your own code to create these blocks](/en/basics/pphlx-components/) rather than rely on pre-built plugins. But thinking about the individual pieces of your site and how they are presented on the page should feel familiar.

## Key Differences between WordPress and PPHLX

When you rebuild your WordPress site in PPHLX, you will notice some important differences:

- A WordPress site is edited using an online dashboard. In PPHLX, you will use a [code editor](/en/editor-setup/) and development environment to maintain your site. You can develop locally on your machine, or choose a cloud editor/development environment like StackBlitz or CodeSandbox.

- WordPress has an extensive plugin and theme market. In PPHLX, you will find some themes and [integrations](https://pphlx.build/integrations/) available, but you may now have to build many of your existing features yourself instead of looking for third-party solutions. Or, you can choose to start with an [PPHLX theme](https://pphlx.build/themes) with built-in features!

- WordPress stores your content in a database. In PPHLX, you will have individual files (typically Markdown or MDX) in your [project directory](/en/basics/project-structure/) for each page's content. Or, you can choose to use a [CMS for your content](/en/guides/cms/), even your existing WordPress site, and use PPHLX to fetch and present the data.

## Switch from WordPress to PPHLX

To convert a WordPress blog to PPHLX, start with our blog theme starter template, or explore more community blog themes in our [theme showcase](https://pphlx.build/themes). 

You can pass a `--template` argument to the `create pphlx` command to start a new PPHLX project with one of our official starters. Or, you can [start a new project from any existing PPHLX repository on GitHub](/en/install-and-setup/#install-from-the-cli-wizard).

  <PackageManagerTabs>
    <Fragment slot="npm">
    ```shell
    npm create pphlx@latest -- --template blog
    ```
    </Fragment>
    <Fragment slot="pnpm">
    ```shell
    pnpm create pphlx@latest --template blog
    ```
    </Fragment>
    <Fragment slot="yarn">
    ```shell
    yarn create pphlx --template blog
    ```
    </Fragment>
  </PackageManagerTabs>

You can continue to [use your existing WordPress blog as your CMS for PPHLX](/en/guides/cms/wordpress/), which means you will keep using your WordPress dashboard for writing your posts. Your content will be managed at WordPress, but all other aspects of your PPHLX site will be built in your code editing environment, and you will [deploy your PPHLX site](/en/guides/deploy/) separately from your WordPress site. (Be sure to update your domain at your host to keep the same website URL!)

You may wish to take [PPHLX's Build a Blog Tutorial](/en/tutorial/0-introduction/) if you are new to working in a code editor and using GitHub to store and deploy your site. It will walk you through all the accounts and setup you need! You will also learn how to [build PPHLX components yourself](/en/tutorial/3-components/), and it will show you how to [add blog posts directly in PPHLX](/en/tutorial/2-pages/2/) if you choose not to use WordPress to write your content.

If you want to move all of your existing post content to PPHLX, you may find this [tool for exporting Markdown from WordPress helpful](https://github.com/lonekorean/wordpress-export-to-markdown). You may need to make some adjustments to the result if you have to [convert a large or complicated WordPress site to Markdown](https://swizec.com/blog/how-to-export-a-large-wordpress-site-to-markdown/).

To convert other types of sites, such as a portfolio or documentation site, see more official starter templates on [pphlx.new](https://pphlx.new). You'll find a link to each project's GitHub repository, as well as one-click links to open a working project in StackBlitz and CodeSandbox online development environments.
