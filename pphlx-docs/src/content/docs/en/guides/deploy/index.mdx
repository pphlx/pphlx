PPHLX projects compile to **standard, optimized PHP and static HTML assets**. This means PPHLX runs natively on almost any web hosting provider in the world without requiring any platform-specific serverless adapters or runtime wrapper packages.

## Recommended Deployment Guides

Choose the deployment type that best fits your hosting setup:

*   **[cPanel & Shared Hosting](/en/guides/deploy/shared-hosting/)** — Simple FTP uploading to Hostinger, Namecheap, or GoDaddy.
*   **[VPS & Custom Servers](/en/guides/deploy/vps/)** — Hosting on DigitalOcean, AWS, or Hetzner with Nginx, Apache, or Caddy.
*   **[PaaS Platforms](/en/guides/deploy/paas/)** — Git-based automatic deployments on Railway, Render, or Heroku.
*   **[Static CDN Hosting](/en/guides/deploy/static-cdn/)** — Zero-cost static CDN deployments to Cloudflare Pages, Vercel, or Netlify (for purely static builds).
