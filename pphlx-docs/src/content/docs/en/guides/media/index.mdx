Because PPHLX runs on a **live PHP server**, you have complete control over media assets. You can process images natively on your host server, store files in cloud object buckets, or leverage third-party optimization CDNs at scale.

## Recommended Media Guides

Choose the media handling architecture that fits your project requirements:

*   **[Local Media Processing (GD & Imagick)](/en/guides/media/local-processing/)** — Crop, resize, compress, and convert images directly on your server using PHP libraries.
*   **[S3-Compatible Cloud Storage](/en/guides/media/cloud-storage/)** — Upload, store, and serve media using S3, Cloudflare R2, or MinIO.
*   **[External Media CDNs (Cloudinary & Mux)](/en/guides/media/external-cdns/)** — Generate dynamic CDN resize URLs and stream HLS video.
