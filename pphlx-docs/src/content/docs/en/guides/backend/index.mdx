PPHLX is a **complete full-stack engine**. Unlike frontend-only frameworks, you have native, direct access to the entire PHP backend ecosystem. You do not need third-party JS-based BaaS platforms to build secure databases or user systems.

## Recommended Backend Guides

Explore the core backend pillars of PPHLX:

*   **[Databases (SQL & ORMs)](/en/guides/backend/databases/)** — Query PostgreSQL, MySQL, or SQLite using native PHP PDO or Eloquent.
*   **[Authentication & Sessions](/en/guides/backend/authentication/)** — Secure your routes with PHP sessions, cookies, or JWTs.
*   **[API Routes & Webhooks](/en/guides/backend/apis-webhooks/)** — Build JSON API endpoints and handle third-party hooks.
*   **[Cloud Databases](/en/guides/backend/cloud-databases/)** — Connect to cloud database engines like Neon, Supabase, or Turso.
