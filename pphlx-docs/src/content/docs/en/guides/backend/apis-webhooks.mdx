---
title: API Routes & Webhooks
description: Create backend API endpoints and handle external webhooks.
---

You can build pure backend API routes, controllers, or process external webhooks (like Stripe) by creating standard PHP files under your source directory.

## JSON API Endpoint

Create a file at `src/api/products.php`:

```php
<?php
header("Content-Type: application/json");

$products = [
    ["id" => 1, "name" => "Wireless Mouse", "price" => 29.99],
    ["id" => 2, "name" => "Mechanical Keyboard", "price" => 79.99]
];

echo json_encode($products);
```

## Processing Stripe Webhooks

Create an endpoint file at `src/api/webhook.php` to handle post requests from external services:

```php
<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $payload = file_get_contents('php://input');
    $sig_header = $_SERVER['HTTP_STRIPE_SIGNATURE'] ?? '';

    // Process webhook event logic here...
    
    http_response_code(200);
    echo json_encode(["status" => "success"]);
} else {
    http_response_code(405);
}
```
