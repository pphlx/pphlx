[Decap CMS](https://decapcms.org/) (formerly Netlify CMS) is an open-source, Git-based flat-file content manager. It allows content creators to edit Markdown files directly in your repository.

## How it works

1. Content creators edit posts in the Decap CMS admin panel dashboard.
2. Changes are saved and committed directly to your GitHub repository as Markdown files.
3. The PPHLX compiler reads these Markdown files at build time and compiles them into static PHP layout structures.

No live database server is required!
