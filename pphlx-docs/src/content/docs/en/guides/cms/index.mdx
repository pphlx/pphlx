Because PPHLX compiles down to **standard PHP**, it can integrate with Content Management Systems in two ways: running directly inside monolithic PHP CMS platforms, or fetching data from headless content APIs.

## Supported Architectures

Choose the CMS integration guide that fits your workflow:

*   **[WordPress Theme & Plugin Development](/en/guides/cms/wordpress/)** — Embed React/Vue component islands natively inside WordPress plugins and themes.
*   **[Statamic Flat-file CMS](/en/guides/cms/statamic/)** — Integrate compiled PPHLX views inside Statamic flat-file layouts.
*   **[Decap CMS (Git-Based)](/en/guides/cms/decap-cms/)** — Manage content as flat Markdown files committed directly to Git.
*   **[Headless APIs (Strapi / Sanity)](/en/guides/cms/headless-api/)** — Fetch dynamic JSON articles from headless APIs at runtime or compile-time.
