PPHLX features **native, out-of-the-box support** for **Qwik**. You can write your component files directly using Qwik and the Go template compiler will compile them into statically-hydrated PHP pages with zero setup.

## Zero Installation & Configuration

Unlike other frameworks, PPHLX does not require you to install any sub-packages or configure any plugins to use Qwik. The built-in compiler and Vite bundler process your files automatically.

Simply write your component files and import them directly into your templates.

## Usage Example

Create your component file (e.g. `MyComponent` with the appropriate framework extension) and import it directly into your template:

```pphlx
@import MyComponent from 'components/MyComponent.jsx'

<!-- index.pphx -->
<div>
  <MyComponent client:visible />
</div>
```
