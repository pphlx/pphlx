:::caution[Removed]
The PPHLX DB integration was deprecated in v6.4 and has been removed since PPHLX v7.0.

If you were using this integration in your project, we recommend migrating to a third-party library for database functionality. See the [PPHLX v7.0 migration guide](/en/guides/upgrade-to/v7/#removed-@astrojsdb) for more details and recommendations on how to update your project.
:::
