PPHLX features **native, out-of-the-box support** for **UnoCSS**. You can write your component files directly using UnoCSS and the Go template compiler will compile them into statically-hydrated PHP pages with zero setup.

## Zero Installation & Configuration

Unlike other frameworks, PPHLX does not require you to install any sub-packages or configure any plugins to use UnoCSS. The built-in compiler and Vite bundler process your files automatically.

Simply write your component files and import them directly into your templates.

## Usage Example

Create your component file (e.g. `MyComponent` with the appropriate framework extension) and import it directly into your template:

```pphlx
<!-- index.pphx -->
<div class="p-6 max-w-sm mx-auto bg-white rounded-xl shadow-lg flex items-center space-x-4">
  <div class="text-xl font-medium text-black">UnoCSS is Ready!</div>
</div>
```
