We welcome contributions of any size and contributors of any skill level. As an open-source project, we are happy to help with guidance on PRs, technical writing, and turning any feature idea into a reality.

---

## Ways to Contribute

### Project Repositories

You can find the core PPHLX repositories on GitHub:

*   **[PPHLX Compiler & Core](https://github.com/pphlx/pphlx)**: The main compiler engine written in Go, including WASM bundles and the dev/build CLI utility.
*   **[PPHLX Playground IDE](https://github.com/pphlx/pphlx-org)**: The web sandbox for live playbook compilation.
*   **[PPHLX VS Code Extension](https://github.com/pphlx/pphlx-vscode)**: Syntax highlighting and tokenization support for `.pphx` files.

### Types of Contributions

Beyond code changes to the compiler, we appreciate contributions in:
*   Writing documentation, playbook examples, and tutorials.
*   Reporting compiler parsing bugs or edge cases with PHP attribute nesting.
*   Suggesting feature requests or improvements in the issue trackers.
