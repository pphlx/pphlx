<Lede> In questo tutorial, imparerai le funzionalità chiave di PPHLX costruendo un blog completamente funzionante, da zero al lancio completo! 🚀 </Lede>

Lungo il percorso, farai:
- Configurare il tuo ambiente di sviluppo
- Creare pagine e articoli del blog per il tuo sito web
- Costruire con componenti PPHLX
- Interrogare e lavorare con file locali
- Aggiungere interattività al tuo sito
- Distribuire il tuo sito sul web

Vuoi un'anteprima di ciò che costruirai? Puoi visualizzare il progetto finale su [GitHub](https://github.com/pphlx/blog-tutorial-demo) o aprire una versione funzionante in un ambiente di codifica online come [IDX](https://idx.google.com/import?url=https:%2F%2Fgithub.com%2Fpphlx%2Fblog-tutorial-demo%2F) o [StackBlitz](https://stackblitz.com/github/pphlx/blog-tutorial-demo/tree/complete?file=src%2Fpages%2Findex.pphx).


:::note
Se preferisci iniziare a esplorare PPHLX con un sito PPHLX pre-costruito, puoi visitare https://astro.new e scegliere un modello di partenza da aprire e modificare in un editor online.
:::
