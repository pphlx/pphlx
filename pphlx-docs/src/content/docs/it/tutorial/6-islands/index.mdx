Ora che hai un blog pienamente funzionante, è il momento di aggiungere alcune isole interattive al tuo sito!

## Guardando avanti

In questa unità, userai le **isole PPHLX** per portare componenti framework frontend nel tuo sito PPHLX.

Farai:
- Aggiungere un framework UI, Preact, al tuo progetto PPHLX
- Usare Preact per creare un componente di saluto interattivo
- Imparare quando potresti _non_ scegliere isole per l'interattività
