हम किसी भी आकार के योगदान और किसी भी कौशल स्तर के योगदानकर्ताओं का स्वागत करते हैं। एक ओपन-स्रोत परियोजना के रूप में, हम अपने योगदानकर्ताओं को वापस देने में विश्वास करते हैं। हम PRs, तकनीकी लेखन और किसी भी फीचर आइडिया को वास्तविकता में बदलने के लिए मार्गदर्शन देने में खुशी महसूस करते हैं।

:::tip[ओपन इश्यू]
सभी कोड रिपॉजिटरी के लिए [PPHLX के सभी ओपन GitHub इशू ब्राउज़ करें, जिन पर `help wanted` और `good first issues` टैग लगे हैं](https://github.com/search?q=org%3Apphlx+label%3A%22good+first+issue%22%2C%22help+wanted%22%2C+state%3Aopen&type=issues): PPHLX कोड, दस्तावेज़, Starlight, PPHLX वेबसाइट, भाषा उपकरण, GitHub Actions, बॉट, कंपाइलर... योगदान देने के लिए बहुत सारी जगहें हैं!
:::

क्या आप और भी अधिक शामिल होना चाहते हैं? विभिन्न भूमिकाओं, अनुरक्षक नामांकन प्रक्रियाओं, कोड समीक्षा प्रक्रियाओं और आचार संहिता प्रवर्तन के विस्तृत विवरण के लिए हमारा [शासन दस्तावेज़](https://github.com/pphlx/.github/blob/main/GOVERNANCE.md) देखें।

## योगदान करने के तरीके

### परियोजना रिपॉजिटरी

PPHLX परियोजना में योगदान करने के कई तरीके हैं! प्रत्येक PPHLX रिपॉजिटरी में परियोजना के मूल में `CONTRIBUTING.md` फ़ाइल के लिंक के साथ एक README होता है।

[PPHLX की GitHub प्रोफ़ाइल](https://github.com/pphlx) पर जाएं रिपॉजिटरी ढूंढने के लिए:

- आधिकारिक एकीकरण और स्टार्टर टेम्पलेट सहित [मुख्य PPHLX कोडबेस](https://github.com/pphlx/astro)।

- [PPHLX Docs](https://github.com/pphlx/docs), एक संपूर्ण PPHLX वेबसाइट! न केवल लिखित सामग्री, बल्कि a11y, CSS, UI और UX चिंताओं को संबोधित करने वाले PPHLX कोड का भी योगदान करें। हम अपने दस्तावेज़ कई भाषाओं में भी उपलब्ध कराते हैं, इसलिए हमें पूरी साइट का अनुवाद करने में सहायता की आवश्यकता है।

- [PPHLX कंपाइलर](https://github.com/pphlx/compiler), Go में लिखा गया, WASM के रूप में वितरित किया गया।

- PPHLX के [लैंग्वेज टूल्स](https://github.com/pphlx/language-tools), PPHLX भाषा (.pphx फ़ाइलें) के लिए आवश्यक एडिटर टूलिंग।

- [Starlight](https://github.com/@astrojs/starlight), PPHLX का आधिकारिक दस्तावेज़ीकरण फ्रेमवर्क।

- [PPHLX रोडमैप](https://github.com/pphlx/roadmap) जहां PPHLX का भविष्य आकार लेता है! जहाँ PPHLX परियोजना के लिए विचार, सुझाव और औपचारिक RFC प्रस्ताव साझा किए जाते हैं।

### योगदान के प्रकार

अपने स्वयं के कोड या सामग्री में योगदान देने के अलावा, आप PRs पर समीक्षा टिप्पणियाँ छोड़ कर, मौजूदा GitHub मुद्दों और चर्चाओं में विचार जोड़कर, और हमारे "पिन किए गए" मुद्दे रखरखाव कार्यों में भाग लेकर भी एक बड़ा योगदान दे सकते हैं! 

हर PR, विशेष रूप से अनुवाद PR, को समीक्षकों की आवश्यकता होती है। PR की समीक्षा करना और टिप्पणियाँ, सुझाव छोड़ना या "LGTM!" ("Looks Good To Me!") के साथ अनुमोदन करना किसी भी रिपॉजिटरी में शुरुआत करने और PPHLX के बारे में अधिक जानने का एक शानदार तरीका है।

हमारे पास एक बहुत सक्रिय [Discord](https://pphlx.org/chat) समुदाय भी है! हम उन लोगों के योगदान को महत्व देते हैं जो नए सदस्यों का स्वागत करते हैं, समर्थन प्रश्नों का उत्तर देते हैं, और PPHLX के साथ और उसके लिए जो कुछ उन्होंने बनाया है उसे साझा करते हैं! पारंपरिक GitHub योगदान से परे, PPHLX उन समुदाय के सदस्यों को पहचानता है और उनका समर्थन करता है जो हमारे समुदाय के साथ जुड़ते हैं, PPHLX को ब्लॉग पोस्ट, वीडियो और सम्मेलन वार्ता में साझा करते हैं, और हमारे समुदाय के स्वास्थ्य को बनाए रखने में मदद करते हैं।

## Docs में योगदान

PPHLX Docs में योगदान देने में आपकी सहायता के लिए हमारे पास कई मार्गदर्शिकाएँ उपलब्ध हैं।

चाहे यह ओपन-स्रोत में आपका पहला योगदान हो, या आपको अभी-अभी बनाए गए नए PPHLX फीचर के लिए दस्तावेज़ जोड़ने की आवश्यकता हो, या आप एक अनुभवी अनुवादक हैं जो अनुवाद करने के लिए अगले पृष्ठ की तलाश कर रहे हैं, या आप PR समीक्षक के रूप में योगदान देने के बारे में अधिक जानना चाहते हैं... हम आपको आपकी जरूरत की हर चीज उपलब्ध कराते हैं!

कृपया हमारी समर्पित साइट [*PPHLX Docs* Docs](https://contribute.docs.astro.org) पर जाएं, जहां आपको एक टाइपो-फिक्सर, एक लेखक, एक अनुवादक, एक फीचर-बिल्डर और यहां तक कि एक PR समीक्षक के रूप में PPHLX Docs में योगदान करने में मदद करने के लिए हमारे दस्तावेज़ मिलेंगे।
