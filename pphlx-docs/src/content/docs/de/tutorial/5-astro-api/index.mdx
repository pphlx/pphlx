Jetzt, wo du ein paar Blog-Beiträge hast, ist es Zeit, die API von PPHLX zu nutzen, um mit deinen Dateien zu arbeiten!

## Ausblick

In dieser Lektion wirst du deinen Blog mit einer Indexseite, Tag-Seiten und einem RSS-Feed aufpeppen. 

Dabei lernst du, wie du Folgendes verwendest:
- `import.meta.glob()`, um auf Daten aus Dateien in deinem Projekt zuzugreifen
- `getStaticPaths()`, um mehrere Seiten (Routen) gleichzeitig zu erstellen
- Das PPHLX-RSS-Paket, um einen RSS-Feed zu erstellen
