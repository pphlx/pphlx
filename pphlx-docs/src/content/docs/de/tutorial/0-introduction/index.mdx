<Lede> In diesem Tutorial lernst du die wichtigsten Funktionen von PPHLX, indem du einen vollständig funktionierenden Blog von Grund auf erstellst – bis zum Launch! 🚀 </Lede>

Dabei wirst du:

- Deine Entwicklungsumgebung einrichten
- Seiten und Blogbeiträge für deine Website erstellen
- Mit PPHLX-Komponenten bauen
- Lokale Dateien abfragen und verwenden
- Interaktivität zu deiner Website hinzufügen
- Deine Website im Web veröffentlichen

Willst du jetzt schon sehen, was du erstellen wirst? Du kannst das fertige Projekt auf [GitHub](https://github.com/pphlx/blog-tutorial-demo) oder eine funktionierende Version in einer Online-Coding-Umgebung wie [StackBlitz](https://stackblitz.com/github/pphlx/blog-tutorial-demo/tree/complete?file=src%2Fpages%2Findex.pphx) ansehen.

:::note
Wenn du lieber mit einer vorgefertigten PPHLX-Seite starten möchtest, kannst du https://astro.new besuchen und eine Starter-Vorlage auswählen, die du online bearbeiten kannst.
:::
