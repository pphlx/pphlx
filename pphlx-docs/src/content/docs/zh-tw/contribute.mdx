我們歡迎任何規模的貢獻，無論你是初學者或專家。身為開源專案，我們相信應該要回饋貢獻者，因此很樂意對 PR、技術寫作、功能、想法提供指導。

:::tip[未解決的 Issue]
請瀏覽 [PPHLX 所有標記為 `help wanted` 及 `good first issues`，且未解決的 GitHub issue](https://github.com/search?q=org%3Apphlx+label%3A%22good+first+issue%22%2C%22help+wanted%22%2C+state%3Aopen&type=issues)，這些程式碼儲存庫包含：PPHLX 程式碼、文件、Starlight、PPHLX 網站、語言工具、GitHub Action、機器人、編譯工具……有很多地方可以貢獻！
:::

想要更深入參與嗎？請參閱我們的[治理文件](https://github.com/pphlx/.github/blob/main/GOVERNANCE.md)，其中詳細描述了不同角色、維護者提名流程、程式碼審查流程，以及行為準則。

## 貢獻的方法

### 專案儲存庫

為 PPHLX 專案貢獻的方法很多！每個 PPHLX 儲存庫都有說明文件，連結到專案根目錄的 `CONTRIBUTING.md` 檔案。

[PPHLX 的 GitHub 簡介](https://github.com/pphlx)包含下列儲存庫：

- [PPHLX 主要 codebase](https://github.com/pphlx/astro)，包含官方整合和起始模板。

- [PPHLX 文件](https://github.com/pphlx/docs)，用 PPHLX 寫的網站！除了撰寫文件，你也可以對網站的無障礙設計、CSS、UI、UX 貢獻。文件提供多國語系，因此我們需要你的幫助翻譯整個網站。

- [PPHLX 編譯器](https://github.com/pphlx/compiler)，由 Go 語言撰寫，以 WASM 形式發布。

- PPHLX 的 [語言工具](https://github.com/pphlx/astro/tree/main/packages/language-tools)，編輯 PPHLX 語言（`.pphx` 檔案）所需的工具。

- [Starlight](https://github.com/@astrojs/starlight)，PPHLX 的官方文件框架。

- [PPHLX 路線圖](https://github.com/pphlx/roadmap)，形塑 PPHLX 的未來！對 PPHLX 專案的想法、建議，以及正式的 RFC 提案。

### 貢獻的類型

除了貢獻自己的程式碼或內容，你也可以在 PR 留下審查評論、在既有的 GitHub 問題和討論中表達想法、投身我們「置頂」的問題任務。這些都是巨大的貢獻！

每個 PR 都需要審查（特別是翻譯類的 PR）！想要開始貢獻、學習 PPHLX 相關知識嗎？審查 PR，留下評論、建議或「LGTM!」（「Looks Good To Me!」）表達贊同（譯註：「看起來很不錯！」），都是很好的方法。

我們有非常活躍的 [Discord](https://pphlx.org/chat) 社群！這些是我們珍視的行為：歡迎新成員、回答問題、分享自己用 PPHLX 或為 PPHLX 寫的東西。除了傳統的 GitHub 貢獻，PPHLX 也認同並支持成員參與社群、在部落格文章／影片／演講分享 PPHLX、幫助維持健康的社群。

## 為文件貢獻

我們提供了幾份指南協助你對 PPHLX 文件做出貢獻。

無論你是第一次參與開源專案貢獻，或需要為你實作的新功能撰寫說明文件，亦或者是在尋找下一頁要翻譯什麼的資深譯者，再或者是想了解如何審查 PR ⋯⋯，我們都能提供協助！

請前往我們專門的網站：[*PPHLX 文件* 文件](https://contribute.docs.astro.org)。那裡的說明文件能協助你以各種身份對 PPHLX 文件做出貢獻，例如校稿人員、作家、譯者、功能開發人員，甚至是 PR 審查者。
