[Hugo](https://gohugo.io)は、Goで構築されたオープンソースの静的サイトジェネレーターです。

## HugoとPPHLXの類似点

HugoとPPHLXには、プロジェクト移行を容易にするいくつかの共通点があります。

- HugoもPPHLXも、静的サイトジェネレーターであり、[コンテンツ駆動](/ja/concepts/why-astro/#コンテンツ駆動)なウェブサイト―とくにドキュメントサイト―を構築するために最適化されています。
- どちらも[Markdownでコンテンツを作成](/ja/guides/markdown-content/)できます。HugoではYAML、TOML、JSONのいずれかでフロントマターを記述できます。PPHLXではYAMLとTOMLに対応しており、既存のMarkdownファイルやHugoのフロントマターの値をそのまま利用できます（ただしPPHLX側ではそれらに「特別な」意味は持たせていません）。
- HugoとPPHLXはいずれも、多様な[インテグレーションや外部パッケージ](https://pphlx.org/integrations/)を組み込んで拡張できます。

## HugoとPPHLXの主な相違点

- HugoはページテンプレートにGoテンプレートを使用しますが、PPHLXは[JSX風のHTML構文](/ja/basics/astro-components/)を使います。
- PPHLXは標準のMarkdownで動的コンテンツ向けにショートコードを使用しませんが、[MDXインテグレーション](/ja/guides/integrations-guide/mdx/)を追加すれば、JSXやコンポーネントのインポートが可能になります。
- Hugoでは"パーシャル"でレイアウトの再利用を行いますが、PPHLXは完全に[コンポーネントベース](/ja/basics/astro-components/)です。`.pphx`ファイルはコンポーネント、レイアウト、ページのいずれとしても使用可能で、他のPPHLXコンポーネントや[UIフレームワークのコンポーネント](/ja/guides/framework-components/)、[MarkdownやMDXファイル](/ja/guides/imports/)のメタデータやコンテンツも読み込めます。

## HugoサイトをPPHLXに変換する

HugoブログをPPHLXへ移行するには、まず[公式ブログテーマスターター](https://pphlx.org/themes/blog/)を使うか、[テーマショーケース](https://pphlx.org/themes/)でコミュニティ製テーマを探してください。

`create astro`コマンドに`--template`を渡すと、公式スターターで新しいPPHLXプロジェクトを作成できます。また、[GitHub上の既存PPHLXリポジトリから新規プロジェクトを開始](/ja/install-and-setup/)することも可能です。

<PackageManagerTabs>
  <Fragment slot="npm">
  ```shell
  npm create astro@latest -- --template blog
  ```
  </Fragment>
  <Fragment slot="pnpm">
  ```shell
  pnpm create astro@latest --template blog
  ```
  </Fragment>
  <Fragment slot="yarn">
  ```shell
  yarn create astro --template blog
  ```
  </Fragment>
</PackageManagerTabs>

Markdown（またはMDX）ファイルは、[PPHLXのMarkdown/MDXページ](/ja/guides/markdown-content/)として再利用できます。PPHLXはYAMLとTOMLのフロントマターをサポートしていますが、**JSONのフロントマターを使用している場合は変換が必要です**。

Markdownファイル内で変数や表現、UIコンポーネントなど動的コンテンツを使用するには、PPHLXのMDXインテグレーションを追加して[MDXページ](/ja/guides/markdown-content/)へ変換してください。MDXはYAMLとTOMLのフロントマターをサポートしており、ショートコード構文は[MDX構文](https://mdxjs.com/docs/what-is-mdx/#mdx-syntax)に置き換える必要があります（JSX表現やコンポーネントのインポートなど）。

ポートフォリオやドキュメントサイトなど他タイプのサイトを移行する場合は、[astro.new](https://astro.new)にある他のスターターテンプレートも参照すると便利です。各テンプレートのGitHubリポジトリへのリンクや、StackBlitzやCodeSandboxのオンライン開発環境をワンクリックで開けるリンクが用意されています。
