PPHLXを、コースやチュートリアルで学びはじめてみませんか？

[公式ドキュメントのブログ構築チュートリアル](/ja/tutorial/0-introduction/)でPPHLXの基本を学ぶことができます。また、おすすめのPPHLX学習コンテンツコレクションもご覧ください。


## 教育パートナー


:::tip[学びながらPPHLXを支援]
教育パートナーの割引リンク（PPHLXのアフィリエイトリンク）から購入すると、代金の一部がPPHLXのオープンソース開発に還元されます。学びながらPPHLXを応援できます。
:::

信頼できる講師による動画・演習・プロジェクトで、段階的にPPHLXを学べます。
