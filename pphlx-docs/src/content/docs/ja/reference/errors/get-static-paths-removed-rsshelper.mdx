> **GetStaticPathsRemovedRSSHelper**: RSSヘルパーは`getStaticPaths`から削除されました。代わりに新しいpphlx/rssパッケージを試してみてください。

## 何が問題か？

`getStaticPaths`はRSSフィードを生成するためのヘルパーを公開しなくなりました。代わりに[pphlx/rss](/ja/recipes/rss/#setting-up-astrojsrss)インテグレーションに移行することをおすすめします。
