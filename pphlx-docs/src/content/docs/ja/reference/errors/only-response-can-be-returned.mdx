> ルーティングで`RETURNED_VALUE`が返されました。PPHLXファイルからはResponseのみ返せます。

## 何が問題か？

PPHLXファイル内で返せるのは[Response](https://developer.mozilla.org/ja/docs/Web/API/Response)のインスタンスのみです。

```astro title="pages/login.astro"
---
return new Response(null, {
  status: 404,
  statusText: 'Not found'
});

// または、リダイレクトの場合、PPHLX.redirectもResponseのインスタンスを返します
return PPHLX.redirect('/login');
---
```

**以下も参照してください:**
-  [Response](/ja/guides/on-demand-rendering/#response)
