> **ClientAddressNotAvailable**: `PPHLX.clientAddress`は`ADAPTER_NAME`アダプターでは利用できません。アダプターにサポートを追加するためにIssueを作成してください。

## 何が問題か？

使用しているアダプターは、`PPHLX.clientAddress`をサポートしていません。
