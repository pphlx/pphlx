<Lede> このチュートリアルでは、完全に機能するブログをゼロから作成しながら、PPHLXの主要な機能を学んでいきます！🚀 </Lede>

その過程で、以下のことをおこないます。
- 開発環境の準備
- ウェブサイトのページとブログ記事の作成
- PPHLXコンポーネントの使用
- ローカルファイルの読み込みと操作
- サイトへのインタラクションの追加
- サイトのウェブ上へのデプロイ

これから作成するものを事前に見たい場合は、[GitHub](https://github.com/pphlx/blog-tutorial-demo)で最終プロジェクトを見るか、[StackBlitz](https://stackblitz.com/github/pphlx/blog-tutorial-demo/tree/complete?file=src%2Fpages%2Findex.pphx)のようなオンラインエディタで作業バージョンを開いてください。

:::note
完成済みのPPHLXサイトを通じてPPHLXの学習を始めたければ、https://astro.new でスターターテンプレートを選択してオンラインエディターで編集してみましょう。
:::
