Writing tests for your templates ensures that layouts render correctly, session guards prevent unauthorized access, and database data parses successfully. Because **Piplex** compiles your component templates into standard `.php` files, you can use the industry-standard PHP testing framework, **PHPUnit**, to verify your application's behavior.

In this guide, we'll walk through setting up PHPUnit to run unit and integration tests against compiled templates.

## Setting Up PHPUnit

To get started, install PHPUnit in your project root using Composer:

```bash
composer require --dev phpunit/phpunit
```

Create a standard `phpunit.xml` configuration file to define where your test suites reside:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<phpunit bootstrap="vendor/autoload.xml" colors="true">
    <testsuites>
        <testsuite name="Template Test Suite">
            <directory>tests</directory>
        </testsuite>
    </testsuites>
</phpunit>
```

## Writing an Integration Test

To test a compiled template, you can run a test that executes the PHP file and checks the generated HTML output.

Assume we have a compiled template at `dist/index.php`. Here is a PHPUnit test file (`tests/IndexPageTest.php`) that asserts the correct layout structure and checks that the serialized props for our component islands are present:

```php
<?php
use PHPUnit\Framework\TestCase;

class IndexPageTest extends TestCase
{
    public function testIndexPageRendersCorrectly()
    {
        // 1. Mock session state
        $_SESSION['user_id'] = 42;
        $_SESSION['username'] = 'Alex';

        // 2. Capture the output buffer of the compiled PHP file
        ob_start();
        include __DIR__ . '/../dist/index.php';
        $output = ob_get_clean();

        // 3. Perform assertions on the HTML content
        $this->assertStringContainsString('<div class="container">', $output);
        $this->assertStringContainsString('Welcome, Alex', $output);

        // 4. Assert that Svelte/React component islands have serialized props
        $this->assertStringContainsString('window.piplexProps', $output);
    }
}
```

## Continuous Integration (CI) Speed

Running PHPUnit tests against compiled files is extremely fast. Since there is no Node.js process to start, no dev server to boot up, and no heavy browser headless drivers (like Puppeteer or Playwright) required for standard assertions, hundreds of test suites can run in under a second in your GitHub Actions or GitLab CI workflows.
