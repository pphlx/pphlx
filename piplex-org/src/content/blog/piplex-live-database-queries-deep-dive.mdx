When building modern web applications, loading dynamic data from databases (such as SQLite, MySQL, or MariaDB) is a fundamental task. In a traditional Single Page Application (SPA) or JAMstack setup, this requires setting up REST/GraphQL endpoints in Node.js, making client-side fetch requests, and handling loading states in your UI components.

Because **Piplex** compiles directly to native PHP, you can run database queries directly on the server inside your templates, and pass that data natively to interactive frontend component islands (React, Vue, Svelte) with zero API boilerplate.

## Step 1: Querying the Database in PHP

Inside a `.pphx` template, you can open a standard PHP code block using the statement bracket `{| ... |}` syntax to query your database using PDO or any PHP query builder:

```pphx
{|
// Establish a database connection
try {
    $pdo = new PDO('mysql:host=localhost;dbname=piplex_db', 'db_user', 'db_pass');
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

    // Fetch dynamic product listings
    $stmt = $pdo->prepare("SELECT id, name, price, stock FROM products WHERE active = 1");
    $stmt->execute();
    $products = $stmt->fetchAll(PDO::FETCH_ASSOC);
} catch (PDOException $e) {
    $products = [];
}
|}
```

## Step 2: Passing Data to Interactive Islands

Now, suppose you have an interactive client-side component (like a Svelte product grid with filters, or a Vue checkout calculator). Instead of building a `/api/products` endpoint and fetching data asynchronously, you can pass your PHP query array directly to the component properties:

```pphx
@import ProductCatalog from '../components/ProductCatalog.svelte'

<div class="shop-container">
  <h1>Featured Catalog</h1>
  <ProductCatalog products={json_encode($products)} client:load />
</div>
```

## Step 3: Zero-Config Hydration Under the Hood

When the Piplex compiler processes your `.pphx` template, it does the following:

1.  **Server-Side Render (SSR)**: The Go compiler compiles a static placeholder block for the island.
2.  **State Serialization**: It automatically serializes the PHP `$products` array into a JSON payload injected into the page's output:
    ```html
    <div id="piplex-productcatalog-171892" class="piplex-island" data-component="ProductCatalog" data-hydrate="load"></div>
    <script>
      window.piplexProps = window.piplexProps || {};
      window.piplexProps["piplex-productcatalog-171892"] = {"products": [...raw database rows...]};
    </script>
    ```
3.  **Hydration**: Svelte loads in the browser and automatically instantiates using the pre-seeded data in `window.piplexProps`.

This means your frontend components mount instantly with correct database records on load, eliminating the latency of client-side loaders while keeping layout code simple and cohesive.
