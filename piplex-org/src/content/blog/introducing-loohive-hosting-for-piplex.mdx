When we set out to build Piplex, our goal was to bring modern component-driven development to monolithic backends and traditional PHP servers without the complexity of managing runtime Node.js processes.

Today, we are thrilled to announce our dedicated hosting solution: **LOOHIVE.com**—the official hosting platform built to deploy and serve Piplex applications with zero server-side setup.

## Why LOOHIVE?

While Piplex is designed to compile to standard PHP that can run on any cheap shared host, **LOOHIVE** provides an optimized, Git-integrated deployment flow that maximizes performance and developer experience.

### 1. Git-to-Deploy Compilation
With LOOHIVE, you don't need to compile files locally and upload them via FTP. Simply push your Piplex source files to GitHub, GitLab, or Bitbucket. LOOHIVE's build servers automatically download your codebase, run the Go-compiled `piplex build` process, and route the outputs instantly:

```bash
git push origin main
# LOOHIVE detects push, runs build, and deploys to production under 15 seconds!
```

### 2. Built-in PHP Runtime & Isolation
LOOHIVE runs an optimized, secure PHP runtime pool (PHP 8.2+) configured specifically to handle compiled `.php` templates. This eliminates the latency of external API requests, serving dynamic pages in under 20ms.

### 3. Integrated Global Static Asset CDN
Whenever you build a project, Piplex compiles your Vue/Svelte/React component islands into static asset bundles. LOOHIVE automatically extracts these static CSS and JS files, pushes them to edge CDN nodes worldwide, and rewrites the asset paths dynamically, ensuring lightning-fast load times for your users.
