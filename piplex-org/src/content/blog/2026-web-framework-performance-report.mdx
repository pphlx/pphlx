The purpose of this report is to look at real-world performance metrics to better understand how framework architecture affects actual user experience on the web. Specifically, we compare how **Piplex** (a compiler that outputs native PHP templates and client islands) compares to heavy SPA-first JavaScript frameworks (like Next.js and Nuxt) and traditional CMS platforms (like WordPress).

We look at:
*   Core Web Vitals (LCP, CLS, INP) in real-world usage.
*   How shipping less JavaScript to the client affects web responsiveness.

## The Core Advantage: Standalone Compiler vs. Heavy SPA Runtimes

Traditional frameworks require a full Node.js process to run server-side rendering (SSR), and they hydrate the entire page in JavaScript. This leads to massive payload sizes and slows down the browser, especially on mobile devices.

Piplex operates on the **Islands Architecture**:
*   Layouts compile to native PHP server code.
*   Only interactive component islands (like Svelte counters or React forms) ship client-side JavaScript.
*   The rest of the page loads instantly as pure static HTML.

## Core Web Vitals Comparison

Google’s Core Web Vitals (CWV) measure actual user experience across three key metrics: load speed (LCP), visual stability (CLS), and responsiveness (INP).

### 1. Largest Contentful Paint (LCP)
LCP measures when the page's main content has likely loaded. For JavaScript-heavy frameworks (Next.js/Nuxt), LCP is often delayed because the browser has to download, parse, and execute massive JS bundles before rendering. 

By compiling templates to raw PHP/HTML server-side, Piplex outputs are served directly by Apache/Nginx. Real-world tests show Piplex pages achieve an average LCP under **1.2 seconds**, matching the speed of pure static sites and beating Next.js averages by over 50%.

### 2. Interaction to Next Paint (INP)
INP measures how responsive a page is to user interactions. SPAs often struggle with INP because the main browser thread is blocked by heavy framework hydration cycles. 

Because Piplex hydrates components lazily (only when they become visible or are interacted with), the browser's main thread remains completely free. This results in consistently excellent INP scores on both mobile and desktop.

## The Cost of JavaScript

The data is clear: websites that ship less JavaScript load faster and feel more responsive. By adopting a server-first compiler model, Piplex allows developers to use React and Svelte at dev time, while shipping up to **90% less JavaScript** to the browser in production.
