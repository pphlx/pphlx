The Piplex team is proud to present the new **[Piplex REPL Sandbox](https://play.piplex.org)**! 

Now you can write Piplex templates and preview compiles directly in your browser. Use it to explore the `.pphx` layout syntax, test React/Vue/Svelte islands side-by-side, or debug rendering issues. 

It is powered by compiling our core **Go-based compiler to WebAssembly (WASM)**, letting it run natively in any web browser and rebuild templates under **20 milliseconds**.

Try it out to see exactly how your template maps to native server-side PHP output code and static client bundles in real-time!
