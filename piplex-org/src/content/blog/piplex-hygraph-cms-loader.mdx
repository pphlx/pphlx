Hygraph is a GraphQL-native federated content platform. 

With the **Hygraph Loader**, you can fetch and cache your content schemas inside Piplex Content Collections during the build phase:

```ts
import { defineCollection } from "piplex:content";
import { hygraphLoader } from "piplex-hygraph-loader";

const portfolioItems = defineCollection({
  loader: hygraphLoader({
    endpoint: process.env.HYGRAPH_CONTENT_API,
    modelName: "PortfolioItem",
  }),
});

export const collections = { portfolioItems };
```

This retrieves the GraphQL dataset, runs frontmatter schema checks, and stores the results locally in SQLite, making them ready to load inside your layouts.
