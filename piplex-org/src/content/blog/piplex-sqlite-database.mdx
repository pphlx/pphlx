Managing thousands of local Markdown or JSON records can slow down compile times in traditional SSG engines. To address this, **Piplex** features a built-in SQLite engine inside its Go-compiled compiler binary.

This allows developers to query content collections natively using SQL, while the compiler caches the structured database records locally on-disk.

## Defining SQLite Collections

You declare your database schemas in `src/content/config.ts` using the Zod validation library:

```ts
import { defineCollection, z } from 'piplex:content';

const products = defineCollection({
  // Use the built-in SQLite database engine
  schema: z.object({
    id: z.string(),
    name: z.string(),
    price: z.number(),
    category: z.enum(['hardware', 'software']),
  }),
});

export const collections = { products };
```

During compilation, Piplex reads your source entries, validates them against the schema, and builds a temporary local SQLite database pool on disk (`.piplex/content.db`), allowing you to fetch records with lightning-fast speeds.
